# CareerPilot - Job Portal

CareerPilot is an AI-powered job portal that connects job seekers, employers, and administrators on a single platform. It helps candidates create professional resumes, search and apply for jobs, while employers can post job openings, review applications, and manage recruitment activities. The platform also provides AI-assisted features such as resume feedback, job description generation, and candidate screening to simplify the hiring process. It is designed to make recruitment faster, more efficient, and user-friendly for both candidates and employers.
